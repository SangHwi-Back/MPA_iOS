# 온보딩 · 앱 잠금

## 1. 이 화면은
- **온보딩:** 최초 설치 후 **1회만** 보여 주는 3장짜리 소개 화면이다.
  - 장마다 메시지는 하나다: 1 기록 → 2 기기 안 분석 → 3 원칙.
  - 끝나면 홈(일기 0개 빈 상태)으로 간다.
  - 설정 › 앱 정보에서 다시 볼 수 있다.
- **앱 잠금:** 설정이나 온보딩 3에서 잠금을 켰을 때, 앱이 다시 열릴 때마다 생체 인증을 요구하는 화면이다.

## 2. 온보딩 공통
- 3장을 좌우로 넘기는 페이지 구조다.
  - iOS: `TabView(.page)` + 커스텀 인디케이터.
  - Android: `HorizontalPager` + 같은 모양의 인디케이터.
- 인디케이터는 현재 장을 긴 막대로 표시한다. 좌우 스와이프로도 이동한다.
- 일러스트는 빈 상태와 같은 라인 드로잉 계열이다(1색 + 포인트색).
  - 동작 줄이기가 꺼져 있으면 1회 애니메이션을 재생한다.
- 제목은 세리프 27, 본문은 16.

**하단 레이아웃**
- **iOS:** 인디케이터를 위에, 전체 폭 [다음] 버튼을 아래에 둔다.
- **Android:** 한 줄에 인디케이터(왼쪽)와 Filled [다음] 버튼(오른쪽)을 둔다.

**[건너뛰기]** (1, 2장에만 있다)
- 탭하면 온보딩 3으로 바로 간다. AI 사용 가능 여부 확인은 건너뛰어도 백그라운드에서 수행한다.
- 모양: iOS는 회색 텍스트, Android는 M3 텍스트 버튼(브랜드 색).

**Android 시스템 뒤로:** 이전 장으로 간다. 1장에서 누르면 앱을 종료한다.

## 3. 온보딩 1 — 짧게 기록하기
- 일러스트: 펜. 펜 선이 그려지는 애니메이션.
- 제목: "하루 몇 줄이면 충분해요"
- 본문: "오늘 있었던 일, 마음에 남은 한 문장. 길게 쓰지 않아도 괜찮아요."
- [다음] → 온보딩 2

## 4. 온보딩 2 — 모든 분석은 기기 안에서
- 일러스트: 기기 안의 자물쇠. 바깥으로 나가는 점선이 끊겨 있다(전송 없음을 시각화).
- 제목: "모든 분석은 이 기기 안에서"
- 본문:
  - iOS: "Apple Intelligence가 이 iPhone 안에서 일기를 읽고 조언을 만들어요. 일기는 어디로도 보내지 않아요."
  - Android: "기기 내 AI가 이 휴대전화 안에서 일기를 읽고 조언을 만들어요. …"
- **AI 사용 가능 확인 (상태 줄):** 이 화면에서 실제로 확인한다.

| 결과 | 표시 |
|---|---|
| 확인 중 | 스피너 + "이 기기를 확인하고 있어요" |
| 가능 | ✓ AI 틴트 카드. iOS: "이 기기에서 Apple Intelligence를 쓸 수 있어요" |
| 다운로드 중 | "AI 모델을 내려받는 중이에요. 준비되면 자동으로 켜져요" (진행률은 표시하지 않음) |
| 불가 | 중립 회색 카드 + 정보 아이콘. "이 기기에서는 AI를 쓸 수 없어요. 일기 앱으로 쓰고, 나중에 설정에서 내 API 키를 연결할 수 있어요." |

- 불가여도 경고 색을 쓰지 않는다.
- 여기서 키 입력을 권하지 않는다. 첫 실행에서는 일기 쓰기에 집중하게 한다. 카드는 탭해도 아무 동작이 없다.
- **확인 방법**
  - iOS: Foundation Models 가용성.
  - Android: Gemini Nano(ML Kit GenAI / AICore) 기능 확인 API.
- [다음] → 온보딩 3

## 5. 온보딩 3 — 나만의 원칙 · 시작하기
- **버블 미리보기:** 예시 데이터(경청, 꾸준함, 솔직함, 휴식, 감사)로 만든 정적 버블이다. 탭할 수 없다.
  - 동작 줄이기가 꺼져 있으면 아래에서 하나씩 떠오른다.
- **제목:** "쌓일수록 나만의 원칙이 보여요"
- **본문:** "일기가 3개 이상 모이면 자주 드러나는 키워드를 원칙으로 보여드려요."
  - AI 불가 기기에서는 "일기를 날짜별로 모아 보고, 나중에 AI를 연결하면 원칙을 찾아드려요"로 바꾼다.

**잠금 토글**
- 라벨: iOS "Face ID로 일기 잠그기", Android "지문·얼굴로 일기 잠그기".
- **기본 켜짐**(개인 일기이기 때문).
- 시작하기를 누를 때 켜져 있으면 생체 인증을 1회 확인한다.
  - iOS: Face ID.
  - Android: BiometricPrompt.
- 인증에 실패하거나 취소하면 꺼짐으로 되돌린다.
- 모양: iOS는 채운 토글. Android는 M3 Switch(꺼짐 = 외곽선 트랙 + 작은 썸).

**알림 토글 "매일 밤 9:30에 알려주기"**
- **기본 꺼짐.**
- 켜면 시스템 알림 권한을 요청한다. Android 13 이상은 `POST_NOTIFICATIONS`.
- 권한을 거부하면 토글을 끄고 안내한다.
  - iOS: 한 줄 안내 "설정 앱에서 알림을 켤 수 있어요".
  - Android: Snackbar "설정에서 알림을 켤 수 있어요" [설정 열기].

**[시작하기]**
- 온보딩 완료를 저장하고 홈(일기 0개)으로 간다.
- 이 장에는 [건너뛰기]가 없다.
- Android 시스템 뒤로를 누르면 온보딩 2로 간다.

## 6. 앱 잠금 화면

### 6.1 잠기는 시점
- 앱이 백그라운드로 가면 **즉시** 잠근다(유예 시간 없음).
  - iOS: `scenePhase`가 inactive가 되는 즉시.
  - Android: `ON_STOP`.
- 작성 중이던 텍스트는 자동 저장되므로 잃지 않는다.
- 알림과 위젯에는 일기 내용을 보여 주지 않는다.

### 6.2 가려진 배경
- **iOS:** 직전 화면을 강한 블러 + 밝은 덮개로 가린다. 글자를 읽을 수 없어야 한다.
  - 앱 전환기와 스크린 녹화에도 같은 덮개를 쓴다.
- **Android:** 내용 없는 단색 화면을 쓴다. 블러된 내용조차 보이지 않게 한다.
  - 최근 앱 화면은 `FLAG_SECURE`로 가린다.

### 6.3 안내와 인증
- 문구: "일기가 잠겨 있어요".
- 보조 문구는 인증 종류에 맞춘다: Face ID / Touch ID / 기기 암호. 예: "Face ID로 열 수 있어요".

**iOS**
- 화면이 뜨면 자동으로 인증을 1회 요청한다.
- 실패하거나 취소하면 [Face ID로 열기] 버튼으로 다시 시도한다.
- 연속으로 실패하면 시스템이 기기 암호로 넘긴다.
- [기기 암호 사용]은 시스템 암호 입력이다(`.deviceOwnerAuthentication`). 앱 자체 PIN은 만들지 않는다.

**Android**
- 앱으로 돌아오면 자동으로 BiometricPrompt를 띄운다.
- 앱이 지정하는 것은 제목 "MPA 잠금 해제"뿐이다. 나머지는 시스템 UI라 제조사마다 다를 수 있다.
- "PIN 사용"을 누르면 기기 PIN/패턴으로 인증한다(`DEVICE_CREDENTIAL` 허용).
- "취소"를 누르면 잠금 화면에 머문다. [잠금 해제] 버튼으로 다시 시도한다.

**성공하면** 덮개가 페이드 아웃되고 직전 화면이 그대로 보인다.

## 7. 저장 데이터
- `onboardingCompleted`: Bool.
- `appLockEnabled`: Bool. 기본값은 온보딩 3 토글 값이다.
- `dailyReminder`: 켜짐 여부 + 시각(기본 21:30).
- AI 가용성 확인 결과는 캐시하지 않는다. 앱을 실행할 때마다 다시 확인한다.
