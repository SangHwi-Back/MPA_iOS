# 설정 · AI 연결

## 1. 이 화면은
- **설정:** AI 연결 상태, 개인정보(잠금), 기록(알림·내보내기), 도움말을 모은 탭이다.
- **AI 연결:** 기기 내장 AI를 쓸 수 없을 때, 사용자가 **자기 API 키(Gemini / OpenAI)**를 연결하는 화면이다.
  - 키는 기기 안에만 저장한다. iOS는 키체인, Android는 Keystore를 쓴다.
  - 개발자 서버를 거치지 않는다.

## 2. AI 엔진 우선순위 (전역 규칙)
1. **기기 내장 AI**를 쓸 수 있으면 항상 우선한다. iOS는 Apple Intelligence, Android는 Gemini Nano.
2. 기기 AI가 없으면 **사용자 API 키**를 쓴다. Gemini 또는 OpenAI 중 하나다.
3. 둘 다 없으면 **일기 앱 모드**로 동작한다. 홈에 AI 경고 버튼이 나타나고 원칙 탭이 숨겨진다.
- 키를 연결한 상태에서 OS 업데이트 등으로 기기 AI를 쓸 수 있게 되면, 자동으로 기기 AI로 바꾸고 키는 보관만 한다.
  - 표시: "기기 내장 AI 사용 중 · 내 키는 대기 중".

## 4. AI 연결 화면

### 4.1 현재 상태 카드
| 상태 | 표시 |
|---|---|
| 연결 안 됨 | 경고 아이콘 + "연결 안 됨" + 원인 문구(미지원 / 꺼짐 / 다운로드 중) + "일기 쓰기는 그대로 사용할 수 있어요." 아래에 키 입력 섹션을 펼친다. |
| 기기 내장 AI 사용 중 | ✓ 아이콘 + "Apple Intelligence로 기기 안에서 분석해요". 키 섹션은 접힌 "고급: 내 API 키 사용" 행으로 비활성이다. |
| 내 키 사용 중 | "Gemini API (내 키) 사용 중" / "OpenAI API (내 키) 사용 중" + 마지막 테스트 결과(예: "연결 테스트 성공 · 방금"). 보조: "AI 카드에는 '✦ Gemini (내 API 키)'로 표시돼요." |
| 키 오류 (만료·한도 초과) | 경고 아이콘 + "키를 확인해 주세요". 홈 AI 카드에도 [키 확인]이 나타난다. |

미지원 원인 문구 예: "이 기기는 Apple Intelligence를 지원하지 않아요. 내 API 키를 연결하면 조언·요약·원칙을 쓸 수 있어요."
- Android는 "Gemini Nano"로 바꿔 쓴다.

**카드 모양:** Android 연결됨 카드는 Secondary Container 색이다. iOS는 흰 카드 + 브랜드 원형 체크.

### 4.2 내 API 키로 연결 (입력 섹션)

**제공자 선택**
- Gemini / OpenAI. iOS는 Segmented Picker, Android는 SegmentedButton.
- 바꾸면 키 필드, 발급 링크, 플레이스홀더가 제공자에 맞게 바뀌고, 입력한 키는 지운다.

**API 키 필드**
- 보안 입력(가려짐). 앞뒤 공백은 자동으로 제거한다.
- 형식 검사: Gemini는 `AIza…`, OpenAI는 `sk-…`로 시작해야 한다. 틀리면 필드 아래 빨간 한 줄 "키 형식을 확인해 주세요".
- **iOS:** [붙여넣기] 텍스트 버튼. 시스템 붙여넣기 허용 안내가 뜬다. 보기 토글은 없다.
- **Android:** OutlinedTextField. 플레이스홀더 "AIza로 시작하는 키".
  - 눈 아이콘으로 보기/가리기를 토글하고, 클립보드 아이콘으로 붙여넣는다.
  - 오류 시 외곽선과 보조 텍스트가 오류 색으로 바뀐다.

**키 발급 방법 링크**
- 제공자의 공식 키 발급 페이지를 연다. iOS는 인앱 브라우저, Android는 Custom Tabs.

**[연결 테스트]**
- 키를 처음 연결하는 경우: 외부 전송 동의(4.3)를 먼저 받는다. 동의하면 테스트 요청을 보내고, 성공하면 키를 저장하고 연결됨 상태로 바꾼다.

| 상태 | 표시 |
|---|---|
| 키 비어 있음 | 버튼 비활성 |
| 테스트 중 | 버튼 안 스피너 "확인 중…" (Android는 원형 진행 표시) |
| 실패 | 인라인 오류 "키가 올바르지 않아요" / "한도를 초과했어요" / "인터넷 연결을 확인해 주세요". 키는 저장하지 않는다. iOS는 버튼 위, Android는 필드 아래. |

**저장·요금 안내 (항상 표시)**
- iOS: "키는 이 기기의 키체인에만 저장되고, 개발자 서버를 거치지 않아요. 요금은 입력한 키의 계정에 부과돼요."
- Android: "…Android 키 저장소에만 저장되고…"

### 4.3 외부 전송 동의 (API 키 최초 연결 시 1회)
**형태**
- **iOS:** `.sheet`(large). 아래로 끌어 닫을 수 있고, 그렇게 닫으면 취소로 처리한다.
- **Android:** ModalBottomSheet(전체 펼침). 시스템 뒤로도 취소로 처리한다.

**제목:** "일기 내용이 Google 서버로 전송돼요". 제공자 이름을 넣는다(Google / OpenAI).

**본문 (필수 고지, 가이드 4.9 문구를 요약·축약하지 않는다)**
- "AI 분석을 위해 일기 내용이 선택한 제공자(Google) 서버로 전송됩니다. 요금과 데이터 처리는 입력한 키의 계정 정책을 따릅니다."

**전송 범위** (✓ 보내는 것 / ✕ 보내지 않는 것을 아이콘과 텍스트로 구분한다)
- ✓ 가능하면 기기에서 줄인 **요약·키워드**만 보내요
- ✓ 조언에 꼭 필요할 때만 본문 일부를 보내요
- ✕ 사진과 사진 캡션은 보내지 않아요
- ✕ 개발자 서버는 거치지 않아요
- 기기 AI가 아예 없는 기기에서는 요약을 기기에서 만들 수 없다. 그래서 "본문 일부" 전송이 실제로 일어날 수 있으니 문구를 과장하지 않는다.

**하단 안내:** "동의는 설정 › AI 연결의 '연결 해제'로 언제든 철회할 수 있어요."

**버튼**
- [동의하고 연결]: 시트가 닫히고 연결 테스트를 실행한다. 성공하면 연결됨 상태가 된다.
- [취소] / 끌어 닫기 / 스크림 / 뒤로: 동의하지 않은 것으로 처리한다. 키를 저장하지 않고 일기 앱 모드를 유지한다.
- 배치: iOS는 세로(동의 Filled 위, 취소 텍스트 아래). Android는 가로(취소 Outlined + 동의 Filled, 동의가 오른쪽).

**동의 기록**
- 제공자와 일시를 기기에 저장한다.
- 제공자를 바꾸면 다시 동의를 받는다.

### 4.4 연결 정보 (연결됨)
**표시 항목**
- 제공자.
- API 키: 마스킹해서 보여 준다(앞 4자 + •••••• + 끝 3자, 예: `AIza••••••3f9`).
  - 전체 키는 다시 보여 주지 않고 복사도 할 수 없다.
- 외부 전송 동의 일자. 표시 전용이다.

**[키 변경]**
- 키 입력 상태로 돌아간다. 같은 제공자면 동의를 다시 받지 않는다.
- 위치: iOS는 행, Android는 키 행 오른쪽 "변경".

**[다시 테스트]**
- 스피너를 보여 준 뒤 상태 카드를 갱신한다.

**[연결 해제] (destructive)**
- 확인을 받는다: "연결을 해제할까요? AI 기능이 꺼지고 일기 앱으로 사용돼요" [연결 해제(빨강) / 취소].
  - iOS: confirmationDialog(액션 시트).
  - Android: AlertDialog.
- 해제하면 키와 동의를 삭제하고 홈에 AI 경고 버튼을 다시 보여 준다. 일기는 그대로 남는다.
- 안내 문구: "연결을 해제하면 키가 키체인(Android: Android 키 저장소)에서 지워지고 외부 전송 동의도 철회돼요. 일기는 그대로 남아요."

**버튼 배치**
- iOS: 리스트 행. "연결 해제"는 별도 그룹의 빨간 행이다.
- Android: Outlined 버튼 쌍(다시 테스트 / 연결 해제). 해제는 오류 색 외곽선이다.
