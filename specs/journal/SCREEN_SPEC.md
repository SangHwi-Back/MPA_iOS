# 일기 — 기록 · 상세 · 에디터

- **Part A — 기록:** 일기를 날짜순으로 보고, 달력으로 찾고, 검색하고, 지우는 탭.
- **Part B — 일기 상세:** 일기 한 편을 읽는 화면.
- **Part C — 일기 에디터:** 일기를 쓰고 고치는 화면.

## Part A — 기록 (리스트 / 캘린더 / 검색)

### 1. 이 화면은
모든 일기를 날짜순으로 훑고, 달력으로 찾고, 검색하고, 지우는 탭.
리스트와 캘린더는 **같은 화면의 두 가지 보기**이고, 검색은 이 화면 위에서 열리는 모드다.

### 2. 상태
| 상태 | 설명 |
|---|---|
| 리스트(기본) | 월 섹션별 일기 리스트. 최신 월이 위에 온다. |
| 캘린더 | 월 그리드와 선택일의 일기. 진입하면 오늘이 선택된다. |
| 검색 중 | 검색 필드가 활성화되고, 키워드 제안과 결과 리스트를 보여 준다. 탭 바·토글·FAB는 숨긴다. |
| 스와이프 삭제 | 행 삭제 후 실행 취소 토스트/스낵바를 띄운다. |
| 빈 상태 (일기 0개) | 일러스트, 안내, 첫 일기 쓰기. 검색은 비활성이고 토글은 숨긴다. |

보기 선택(리스트/캘린더)은 앱을 다시 열어도 **마지막 선택을 기억**한다.

### 3. 요소 명세 — 리스트

#### 3.1 상단 영역
- **iOS:** Large Title "기록" + (+) 버튼(trailing) + `.searchable` 검색 필드.
  - 플레이스홀더: "제목, 본문, 키워드 검색".
  - 스크롤하면 Large Title과 함께 접혀 들어가고, 아래로 당기면 다시 나타난다.
- **Android:** Top App Bar와 제목 대신 M3 **SearchBar**("기록 검색")가 상단을 차지한다.
  - 스크롤해도 고정되고, 스크롤 시 뒤 배경이 surface container로 바뀐다.
- 검색 필드나 SearchBar를 탭하면 검색 모드로 들어간다(3.9).
- 검색 대상은 제목, 본문, 키워드다.

#### 3.2 새 일기 버튼
- **iOS:** (+) 버튼. **Android:** Extended FAB "쓰기". 스크롤 다운 시 아이콘 FAB로 축소된다.
- 탭하면 오늘 날짜로 새 일기 에디터를 연다.

#### 3.3 리스트 / 캘린더 토글
- 탭하면 같은 화면에서 보기를 전환한다(크로스페이드).
- **iOS:** Segmented Picker.
- **Android:** M3 SegmentedButton. 선택된 세그먼트에 체크 아이콘과 Secondary Container 색을 쓴다.

#### 3.4 월 섹션 헤더
- 형식: "2026년 10월 · N편".
- 스크롤 시 상단에 고정된다(sticky).

#### 3.5 일기 리스트 아이템
**구성**
- 날짜 블록: 일 숫자(세리프) + 요일.
- 제목. 없으면 본문 첫 줄을 쓴다.
- 본문 2줄.
- 썸네일: 사진이 있을 때만, 정사각 60pt, radius 12. 첫 장을 쓰고, 여러 장이면 우하단에 "+N" 배지를 붙인다.
- 키워드 칩: 최대 2개 (`Journal.maxKeywordsInList`).

**동작**
- 탭하면 일기 상세로 간다.
  - iOS: 줌 전환.
  - Android: shared element 전환(날짜, 제목, 썸네일).
- 왼쪽으로 스와이프하면 삭제한다(3.8).
- 길게 누르면 메뉴(편집 / 공유 / 삭제)가 열린다.
  - iOS: 미리보기가 있는 contextMenu.
  - Android: DropdownMenu.

#### 3.6 키워드 칩 (AI)
- 표시 전용이다. 칩을 탭하면 아이템을 탭한 것과 같다.
- 모양: AI 틴트 배경 + 원칙 색 점(최근성).
- 분석 전에는 칩 자리를 비워 둔다. AI 불가면 칩을 숨긴다.
- 모서리: iOS는 캡슐, Android는 radius 8.

#### 3.7 탭 바에서 "기록" 다시 탭
- 맨 위로 스크롤한다.

#### 3.8 스와이프 삭제 + 실행 취소
- 확인 알럿이나 다이얼로그 없이 바로 삭제하고, 실행 취소로 복구한다.

**iOS**
- 구현: `.swipeActions(edge: .trailing, allowsFullSwipe: true)`.
- 스와이프하면 빨간 "삭제" 버튼이 나오고, 탭하면 삭제한다.
- 끝까지 밀면(full swipe) 바로 삭제한다. medium 햅틱.
- 한 번에 한 행만 열린다. 다른 곳을 탭하거나 스크롤하면 닫힌다.

**Android**
- 구현: `SwipeToDismissBox`(끝에서 시작 방향).
- 배경: danger 색 + 휴지통 아이콘 + "삭제". 임계점 전에는 배경 채도를 낮춘다.
- 행 폭의 40% 이상 밀고 놓으면 삭제하고, 미만이면 원위치로 돌아간다.
- 임계점을 넘을 때 햅틱 `GESTURE_THRESHOLD_ACTIVATE`.

**삭제 후 공통**
- 행이 접히며 사라지고 "'{제목}'을 삭제했어요 [실행 취소]"를 띄운다.
- [실행 취소]를 누르면 일기, 사진, 키워드를 원래 자리로 복원한다(행이 다시 펼쳐짐).
- 연속으로 삭제하면 토스트를 마지막 건으로 교체한다. "2편을 삭제했어요"처럼 합치지 않는다.

**실행 취소 토스트의 플랫폼 차이**
| | iOS | Android |
|---|---|---|
| 형태 | 커스텀 어두운 캡슐 토스트 (시스템 토스트가 없음) | M3 Snackbar (radius 8, inverse surface) |
| 위치 | 탭 바 위 16pt | Navigation Bar 위 16dp. FAB를 그 위로 밀어 올림 |
| 유지 시간 | 5초 | 4초 (`SnackbarDuration.Short`). 스와이프로 닫을 수 있음 |
| 스크린리더 | VoiceOver는 즉시 안내하고 10초 유지 | TalkBack이 켜져 있으면 Indefinite |

**길게 누르기 메뉴의 "삭제"**도 같은 흐름을 따른다.

**영구 삭제 시점**
- 토스트가 사라질 때 영구 삭제한다. 이때 키워드와 원칙을 다시 계산한다.
- 실행 취소하면 다시 계산하지 않는다.

#### 3.9 검색 모드
**진입과 종료**
- **iOS:** `.searchable`이 활성화되면 내비게이션 바로 올라간다. "취소"를 누르면 이전 보기로 돌아간다.
- **Android:** SearchBar가 전체 화면 SearchView(배경 surface container)로 확장된다.
  - ← 버튼이나 시스템 뒤로를 누르면 종료한다. Predictive Back으로 SearchBar로 축소되는 애니메이션이 나온다.
- 검색 중에는 Large Title, 토글, 탭 바, FAB를 숨긴다.

**입력**
- 입력하는 즉시 검색한다(250ms 디바운스).
- 지우기 버튼: iOS는 원형 ⊗, Android는 ✕.

**검색어가 없을 때**
- 최근 검색을 최대 5개 보여 준다. 각각 삭제할 수 있다.
- Android는 각 항목에 시계 아이콘을 붙인다.

**키워드 제안 (AI)**
- 검색어가 원칙/키워드 이름과 일치하거나 포함될 때만 보여 준다. 최대 3개.
- 내용: 원칙 색 점 + "{키워드} 키워드로 모아 보기" + 편 수.
- 탭하면 키워드별 일기 목록(전체 화면 리스트)으로 간다. 키워드 시트와 같은 내용이다.
- AI 불가면 숨긴다.
- 모양: iOS는 틴트 카드, Android는 M3 검색 제안 행(↗ 아이콘).

**결과 리스트**
- 헤더: "제목·본문 N편". 최신순.
- 일치하는 부분을 하이라이트한다(#F6E2B4, 다크 #5A4A22).
- 본문 일치가 2줄 밖에 있으면 일치 문장 앞을 "…"로 잘라서 보여 준다.
- 날짜 블록 아래에는 요일 대신 **월**을 표기한다. 여러 달이 섞이기 때문이다.
- 결과를 탭하면 상세로 간다. 뒤로 돌아오면 검색 상태가 그대로 유지된다.

**결과 없음과 키보드**
- 결과가 없으면 "'○○'에 맞는 기록이 없어요" 한 줄과 아이콘을 보여 준다. 일러스트는 없다.
- 결과를 스크롤하면 키보드가 내려간다. Android는 `imeNestedScroll`.

### 4. 요소 명세 — 캘린더

#### 4.1 월 이동
- ‹ › 버튼이나 그리드 좌우 스와이프로 이전/다음 달로 간다.
- 월 제목을 탭하면 연·월 선택이 열린다.
  - iOS: `.wheel` DatePicker 팝오버.
  - Android: "2026년 10월 ▾" 메뉴 버튼이 연도·월 선택 그리드로 바뀐다(M3 DatePicker 헤더 패턴, 화살표 48dp).
- 현재 달 이후와 첫 일기보다 이전 달은 비활성이다. 비활성 화살표 색은 #C9C2B8.

#### 4.2 월 그리드
**동작**
- 날짜를 탭하면 아래 목록이 그 날 일기로 바뀐다. 화면은 이동하지 않는다.
- 같은 날짜를 다시 탭했을 때 일기가 1편이면 바로 상세로 간다.

**표시**
- 점 = 일기 있음, 채운 원 = 선택, 테두리 = 오늘. 미래 날짜는 비활성이다.
- 주 시작 요일은 시스템 설정을 따른다(한국 기본: 일요일).

**크기와 접근성**
- 셀 크기: iOS 46pt 이상, Android 48dp.
- 날짜 셀 라벨: "10월 27일, 일기 있음, 선택됨".

#### 4.3 선택일 헤더와 일기
- 헤더 예: "10월 27일 화요일".
- 아래 목록은 리스트 아이템과 같은 컴포넌트를 쓴다(구분선 없음). 탭하면 상세로 간다.
- 일기가 없는 날: "이 날의 기록이 없어요" + [이 날짜로 쓰기]. 해당 날짜로 새 에디터를 연다.
- 기록이 없는 달: 그리드는 그대로 두고 아래에 "이 달의 기록이 없어요"를 보여 준다.

#### 4.4 캘린더 보기의 새 일기 버튼
- 항상 **오늘 날짜**로 연다. 다른 날짜는 [이 날짜로 쓰기]를 쓴다.
- Android는 캘린더 보기에서 아이콘 FAB(축소형)를 쓴다.

### 5. 빈 상태 (일기 0개)
- 검색은 흐리게 비활성이고, 리스트/캘린더 토글은 숨긴다. 첫 일기를 저장하는 즉시 둘 다 활성화한다.
- 일러스트: 달력 라인 드로잉(`empty_journal`, 170×130). 홈 첫 실행 일러스트와 같은 선 굵기와 색을 쓴다.
- 문구: "아직 기록이 없어요 / 첫 일기를 쓰면 여기에 날짜별로 차곡차곡 모여요."
- **첫 일기 쓰기**
  - iOS: 화면 중앙 Primary 버튼.
  - Android: 화면 안 버튼 없이 Extended FAB "첫 일기 쓰기"(Primary 강조).
  - 저장 후 돌아오면 새 일기가 아래에서 떠오르며 리스트에 추가된다.

### 6. 데이터 의존
- `Journal`: `day`, `displayTitle`, `previewText`, `photos`(`thumbnail`, 장수), `visibleKeywords.prefix(2)`.
- 검색 인덱스: `title`, `body`, `keywords.name`.
- 최근 검색: 로컬 저장, 최대 5개.
- 삭제는 soft-delete로 처리한다. 실행 취소 시간이 끝나면 하드 삭제하고 원칙을 다시 계산한다.

## Part B — 일기 상세 (읽기 모드)

### 1. 이 화면은
일기 한 편을 **읽기 위한** 화면이다. 편집은 하지 않고, 편집 버튼으로 에디터에 들어간다.
읽기에 집중하도록 탭 바(Android는 Navigation Bar와 FAB)를 숨긴다.

### 2. 레이아웃 (위 → 아래)
1. 상단 바: 뒤로 + (편집, 더보기)
2. 키워드 칩 행 (AI)
3. 날짜 · 시각 — 예: "2026년 10월 27일 화요일 · 오후 9:40"
4. 제목 (세리프 28)
5. 본문 (Body 17 / 줄간격 1.75, 문단 간격 16)
6. 사진 그리드
7. AI 한마디 (접힘)
8. 수정 시각 — "마지막 수정 10월 27일 오후 9:52"

### 3. 요소 명세

#### 3.1 뒤로
- 진입한 화면(기록, 홈, 검색, 원칙)으로 돌아간다.
- **iOS:** Liquid Glass 원형 뒤로 버튼(라벨 없음), 또는 왼쪽 엣지 스와이프. 줌 전환을 역방향으로 재생한다.
- **Android:** Top App Bar의 ←, 또는 시스템 뒤로. Predictive Back 제스처 중에는 상세 카드가 줄어들며 뒤의 목록이 비쳐 보인다.
- 검색에서 들어왔으면 돌아갈 때 검색 상태를 유지한다.

#### 3.2 편집 · 더보기
- **편집(✎):** 같은 일기를 에디터로 연다. 시트가 아니라 제자리에서 전환한다.
- **더보기:** 메뉴를 연다.
  - 공유: 텍스트 또는 이미지 카드
  - 날짜 변경
  - 삭제 (빨강)
- **삭제:** 확인 없이 기록 목록으로 돌아가고 실행 취소 토스트/Snackbar를 띄운다. 이후 흐름은 → Part A 3.8.
- **iOS:** 두 버튼을 한 Glass 캡슐로 묶는다(ToolbarItemGroup). 더보기는 가로 ⋯ + Menu.
- **Android:** Small Top App Bar actions에 IconButton 2개. 더보기는 세로 ⋮ + DropdownMenu.

#### 3.3 키워드 칩 (AI)
- 최대 5개(`Journal.maxKeywordsInDetail`). 영향도 순으로 정렬하고, 원칙 색 점으로 최근성을 표시한다.
- 칩을 탭하면 키워드 시트가 열린다(3.10).
- **상태별 표시**
  | 상태 | 표시 |
  |---|---|
  | 분석 중 | 스켈레톤 칩 2개 |
  | 저장 직후, 아직 분석 전 | 숨김 |
  | AI 불가 | 행 전체 숨김 |
- **모양:** iOS는 캡슐. Android는 M3 Assist chip(radius 8, 1dp 외곽선).

#### 3.4 날짜 · 시각
- 일기 날짜와 작성 시각을 보여 준다.

#### 3.5 제목
- 세리프 28. 길이 제한 없이 줄바꿈한다.
- 제목이 없으면 이 줄을 숨기고 본문부터 시작한다. 이때 상단 바에는 날짜를 표시한다.

#### 3.6 본문
- 텍스트를 선택하고 복사할 수 있다.
- 두 번 탭해도 편집으로 가지 않는다(실수 방지).
- 화면에서 대비가 가장 높은 요소다.
- 글꼴 크기 200%(Dynamic Type)까지 단일 컬럼을 유지한다.

#### 3.7 사진 그리드
- **배치:** 1장이면 전체 폭 4:3, 2장 이상이면 2열 정사각.
- 캡션이 있으면 사진 아래에 보여 주고, 없으면 캡션 줄을 생략한다. 사진이 없으면 섹션을 숨긴다.
- **탭:** 전체 화면 사진 뷰어로 간다. 좌우 스와이프로 넘기고, 캡션을 보여 준다.
  - iOS: 아래로 스와이프하면 닫힌다.
  - Android: shared element 전환, 뒤로를 누르면 닫힌다.
- 로딩 중이거나 파일이 없을 때는 MPA-ImagePlaceholder를 쓴다.

#### 3.8 AI 한마디
**접힘 / 펼침**
- 기본은 접힘. 헤더 "이 일기에 대한 AI 한마디"를 탭하면 제자리에서 펼쳐지고, 다시 탭하면 접힌다.
- 펼침 상태는 일기별로 기억하지 않는다. 다시 들어오면 접혀 있다.

**생성과 캐시**
- 처음 펼칠 때 생성한다: 스켈레톤 2줄 + shimmer → 단어 단위로 페이드 인.
- 실패하면 카드 안에 [다시 시도]를 보여 준다.
- 생성한 결과는 캐시한다. 일기를 수정하면 캐시를 버리고 다음에 펼칠 때 다시 생성한다.

**본문**
- 1–2문장, 제안형 톤.
- 출처가 이 일기 자체이므로 출처 칩은 없다.

**엔진 라벨**
- iOS: "✦ Apple Intelligence로 기기에서 생성됨"
- Android: "✦ 기기 내 AI로 생성됨"
- API 키 모드: "✦ Gemini (내 API 키)" / "✦ OpenAI (내 API 키)"

**피드백·다시 생성:** 홈 조언 카드와 같다 (토글 + 햅틱, ↻). 터치 영역 44pt / 48dp.

**민감한 내용이 감지되면** AI 한마디 대신 도움 리소스 카드를 보여 준다.
- ✦ 표식과 피드백이 없고, 접히지 않고 항상 펼쳐져 있다.
- 문구: "마음이 많이 무거운 날이었나 봐요 / 혼자 견디지 않아도 괜찮아요. 지금 이야기를 들어줄 곳이 있어요."
- 버튼: [109 자살예방상담전화], [다른 상담 창구].
  - Android 전화 버튼은 `ACTION_DIAL` 인텐트를 쓴다.
- 홈 조언 카드도 같은 컴포넌트로 교체한다.

**AI 불가:** AI 한마디 섹션과 키워드 칩 행을 숨긴다. 나머지 레이아웃은 그대로다.

#### 3.11 키워드 시트
- 상세 화면에서 열리는 유일한 시트다.

**열기와 닫기**
- 키워드 칩을 탭하면 열린다. 뒤의 일기는 살짝 어두워진다.
- **iOS:** `.sheet` + `presentationDetents([.medium, .large])`, iOS 26 떠 있는 Glass 시트.

  - 아래로 끌기, ✕, 배경 탭으로 닫는다.
- **Android:** ModalBottomSheet. 가장자리에 붙고, 위쪽 radius 28, 드래그 핸들, 스크림 32%.
  - 처음에는 부분 펼침으로 열린다. 위로 끌면 전체 높이가 된다.

**헤더**
- 원칙 색 점 + 키워드 이름 + "N개의 일기에서 발견 · 처음 9월 14일".

**원칙에서 자세히 보기**
- 라벨: iOS "›", Android "→".
- 탭하면 시트가 닫히고 원칙 탭으로 전환한 뒤 해당 원칙 상세를 연다.
- 현재 원칙(상위 5개)이 아닌 키워드면 링크를 숨기고 "지금은 원칙 순위 밖이에요"를 보여 준다.

**관련 일기 목록**
- 이 키워드가 추출된 **모든** 일기를 최신순으로 보여 준다. 홈 버블 메뉴는 상위 3개만 보여 주는 것과 다르다.
- 행 높이 56. 시트 안에서 스크롤한다.
- 현재 보고 있는 일기는 틴트와 "지금 보는 일기" 라벨로 표시하고, 탭할 수 없다.
- 행을 탭하면 시트가 닫히고 그 일기 상세로 이동한다. 뒤로 가면 원래 일기로 돌아온다.
- 행 끝 표시: iOS는 ›, Android M3 리스트 행에는 화살표가 없다.

### 3. 요소 명세

#### 3.1 닫기 (✕)
- 탭하면 에디터를 닫는다. 내용이 있으면 이미 자동 저장되어 있으므로 확인을 묻지 않는다.
- 제목, 본문, 사진이 **모두** 비어 있으면 일기를 만들지 않고 버린다 (`Journal.isEmpty`).
- **iOS:** 시트를 아래로 끌어 닫을 수도 있다.
- **Android:** ← 버튼이나 시스템 뒤로도 같은 역할을 한다.

#### 3.2 완료
- 탭하면 저장을 확정하고 키워드 분석을 시작한다. 키보드가 내려가고 "작성 후" 상태가 된다.
- 한 번 더 닫으면 이전 화면으로 돌아간다.
- 제목과 본문이 비어 있으면 비활성이다. 별도의 큰 저장(Update) 버튼은 없다.
- 첫 저장이 확정되면 완료 자리가 더보기로 바뀐다.
- **iOS:** 체크 아이콘이 있는 원형 버튼(44pt, #2E3A6E).
- **Android:** 텍스트 "완료" Filled 버튼(M3 앱 바 액션).

#### 3.3 자동 저장 표기 · 더보기 (작성 후)
- 입력이 1초 멈출 때마다 저장한다.
- 표기는 "저장 중…" → "저장됨 · 오후 9:41" 순으로 바뀐다. Android는 체크 아이콘을 붙인다.
- 저장에 실패하면(저장 공간 부족 등) 경고색 "저장 안 됨 · 다시 시도"로 바뀌고, 탭하면 다시 시도한다.
- 더보기 메뉴: 날짜 변경 / 글감 다시 보기 / 삭제.
- **위치:** iOS는 가운데 캡션. Android는 앱 바 제목 자리에 왼쪽 정렬.

#### 3.4 날짜 텍스트 버튼
- 예: "10월 30일 금요일 ▾". 기본값은 진입한 날짜(보통 오늘)다.
- 탭하면 날짜 피커가 열린다(3.10).

#### 3.5 글감 (AI 질문)
- 제목 위에 질문을 보여 준다. 예: "오늘 누군가의 말을 끝까지 들었던 순간이 있었나요?"
- ✕를 누르면 글감을 제거한다.
- 도구 바의 "✦ 글감"을 누르면 새 질문을 생성해 이 자리에 보여 준다.
- 글감은 저장할 때 일기와 함께 보관한다(`Journal.prompt`). 상세 화면에는 보여 주지 않는다.

#### 3.6 제목
- 박스와 밑줄이 없는 세리프 28. 플레이스홀더는 "오늘의 제목"이고, 입력은 선택이다.
- 줄바꿈 키를 누르면 본문으로 이동한다.
- Android는 TextField 장식을 제거한다.

#### 3.7 본문
- 새 일기면 들어오자마자 포커스가 간다.
- 플레이스홀더: "떠오르는 대로 몇 줄 적어보세요."
- 높이 제한 없이 페이지 끝까지 늘어난다. 커서가 키보드에 가려지지 않게 한다.
  - Android는 `bringIntoView`를 쓴다.

#### 3.9 사진 썸네일 (작성 후)

**동작**

- 우상단 ✕: 사진을 삭제하고 실행 취소 토스트/Snackbar를 띄운다.
  - ✕ 버튼은 반투명 #1C1B1A 62% 원 + 흰 X이고, 썸네일 모서리에서 4pt 안쪽에 둔다.
- 점선 + 타일: 사진 보관함을 연다.
- 길게 눌러 끌기: 순서를 바꾼다.

#### 3.10 날짜 선택
**공통 규칙**
- 미래 달과 미래 날짜는 비활성이다. 일기는 지난 날짜까지만 쓸 수 있다.
- 채운 원 = 선택, 회색 점 = 이미 일기가 있는 날.
- 같은 날에 여러 편을 허용한다. 막지 않고 점으로만 알린다.

**iOS**
- 구현: DatePicker(`.graphical`) 팝오버 + 커스텀 점 표시.
- 날짜를 누르면 즉시 반영되고 팝오버가 닫히며 자동 저장한다.
- 월 헤더 "2026년 10월 ›"를 탭하면 연·월 휠로 전환한다. ‹ ›로 이전/다음 달로 간다.
- 오늘은 진한 글자로 표시한다.
- 아래 안내 줄: "● 점이 있는 날은 이미 일기가 있어요" (색만으로 의미를 전달하지 않기 위해).
- VoiceOver: "10월 27일, 일기 있음".

**Android**
- 구현: M3 DatePickerDialog(모달).
- 헤드라인에 선택한 날짜(예: "10월 28일 (수)")를 크게 보여 준다.
- ✎를 누르면 텍스트 입력 모드(YYYY. MM. DD.)로 바뀐다.
- "2026년 10월 ▾"를 누르면 연도 그리드가 열린다.
- 오늘은 테두리로 표시한다. 셀 터치 영역 48dp.
- [확인]을 눌러야 반영되고 자동 저장한다. [취소], 스크림, 뒤로를 누르면 변경 없이 닫힌다.
- 점 안내 문구 대신 TalkBack 라벨 "일기 있음"을 쓴다.

**날짜가 바뀌면 함께 바뀌는 것**
- 목록과 캘린더에서 일기 위치가 바뀐다.
- "오늘의 일기"였다면 홈의 오늘 카드를 갱신한다.
- 키워드 최근성도 새 날짜를 기준으로 다시 계산한다.

#### 3.11 발견한 키워드 (AI, 작성 후)
**분석 진행**
- 완료(✓) 직후: "키워드를 찾는 중…" + 스켈레톤 칩 2개를 보여 준다.
- 분석이 끝나면 칩이 하나씩 페이드 인한다.
- 내용이 바뀌면 다시 분석한다. 이때 사용자가 지우거나 추가한 키워드는 유지한다.

**편집**
- 칩의 ✕: 이 일기에서 키워드를 제외한다(`isExcluded = true`). 원칙 재계산에 반영된다.
- "+ 추가": 키워드를 직접 입력하거나(2–4글자 권장, `keywordLength`) 기존 원칙에서 고른다. `source = .user`로 저장한다.

**모양**
- iOS: 캡슐 칩.
- Android: M3 Input chip(radius 8). 닫기 아이콘 터치 영역 28dp.

**엔진 라벨:** 기기 / "✦ Gemini (내 API 키)" / "✦ OpenAI (내 API 키)".
