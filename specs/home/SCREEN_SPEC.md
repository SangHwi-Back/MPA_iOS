# 홈 (오늘 탭)

- **Part A — 홈 화면:** 홈의 요소, 동작, 상태.
- **Part B — AI 카드 상태 · 다크 모드:** 홈의 조언·글감·주간 요약 카드를 비롯해, 다른 화면의 AI 카드도 함께 따르는 상태 규칙과 다크 모드 규칙.

## Part A — 홈 (오늘 탭)

### 1. 이 화면은
앱을 열면 처음 보이는 "오늘" 탭. 오늘 쓸 거리(글감)와 AI가 지난 일기에서 찾은 조언·원칙·주간 요약을 한 화면에 모은다.
AI를 쓸 수 없으면 AI 영역을 통째로 빼고 **일기 앱 모드**(주간 스트립 + 최근 기록)로 바뀐다.

- 기준 폭: iOS Compact 390pt / Android Compact 412dp. 콘텐츠 최대 폭 640, 좌우 여백 20.
- 첫 화면 경계: iOS 844pt, Android 915dp. 그 아래는 스크롤 영역이다.

### 2. 화면 상태를 정하는 입력값
| 입력 | 값 | 영향 |
|---|---|---|
| `aiAvailability` | 기기 AI 가능 / API 키 모드 / 불가 / 모델 다운로드 중 | 불가·다운로드 중이면 AI 섹션을 숨기고 AI 경고 버튼을 보여 준다(일기 앱 모드). |
| `journalCount` | 0 / 1–2 / 3 이상 | 0이면 첫 실행 빈 상태, 1–2개면 원칙 진행 표시, 3개 이상이면 원칙 버블을 보여 준다. |
| `todayJournal` | 없음 / 있음 | 없으면 오늘의 글감 카드, 있으면 오늘 일기 미리보기 카드를 보여 준다. 새 일기 버튼은 오늘 일기를 편집으로 연다. |
| `thisWeekCount` | 0 / 1 이상 | 0이면 이번 주 요약을 숨긴다. |
| 시각 | 5–11시 / 오후 / 저녁 / 밤 | 인사 문구가 바뀐다. 첫 실행(일기 0개)에서는 항상 "반가워요"다. |

#### 상태 매트릭스
| 상태 | 보이는 섹션 (위→아래) | 탭 |
|---|---|---|
| AI 사용 가능 · 일기 3개 이상 | 인사+날짜 → 오늘의 조언 → 오늘의 글감 또는 오늘 일기 미리보기 → 나의 원칙 버블+범례 → 이번 주 요약(접힘) | 오늘·기록·원칙·설정 |
| AI 사용 가능 · 일기 1~2개 | 인사 → 오늘의 조언(짧게) → 글감 또는 미리보기 → 원칙 빈 상태+진행 바(n/3) | 4탭 |
| 일기 0개 (첫 실행) | "반가워요" → 빈 상태 일러스트+안내 → 첫 일기 쓰기 → 예시 질문 3개 → 프라이버시 한 줄 | 4탭(원칙 탭은 빈 상태) |
| AI 없음 (일기 앱 모드) | 인사 → 오늘의 일기 카드(고정 문구) → 이번 주 스트립 → 최근 기록(5개) | **오늘·기록·설정 3탭** |

### 3. 요소 명세

#### 3.1 새 일기 버튼
- **iOS:** 내비게이션 바 trailing에 있는 Liquid Glass 원형 (+) 버튼.
- **Android:** 우하단 Extended FAB "쓰기". 상단 앱 바에는 쓰기 버튼을 두지 않는다.

**동작**
- 탭하면 오늘 날짜로 새 일기 에디터를 연다.
  - iOS: 시트, large detent, light 햅틱.
  - Android: 전체 화면, 컨테이너 트랜스폼.
- 오늘 일기가 이미 있으면 그 일기를 편집 모드로 연다.

**Android FAB 변형**
- 스크롤 다운 시 아이콘만 있는 FAB로 축소되고, 스크롤 업 시 다시 확장된다.
- 오늘 일기가 있으면 라벨이 "이어 쓰기"로 바뀐다. iOS (+) 버튼은 모양이 그대로이고 동작만 바뀐다.
- 첫 실행이면 라벨이 "첫 일기 쓰기"이고 Primary(#2E3A6E)로 강조된다. 첫 저장 후에는 "쓰기"와 Primary Container 색으로 돌아간다.

**이동:** 일기 에디터

#### 3.2 인사 + 날짜 (Large Title)
- **동작:** 없음(정적). 스크롤하면 축소된다.
  - iOS: 인라인 "오늘"로 줄어든다.
  - Android: Small Top App Bar "오늘"로 줄어든다.
- **인사:** 시간대별로 아침(5–11시) / 오후 / 저녁 / 밤.
- **날짜:** 로케일 포맷을 따른다. 예: "10월 30일 금요일", en "Friday, October 30".
- **iOS/Android 차이:** iOS는 날짜가 인사 **위**에 있다. Android는 M3 subtitle 규칙에 따라 제목 **아래**에 있다.
  - Android actions 영역은 평소 비어 있고, AI 불가 시 경고 IconButton만 들어간다.

#### 3.3 오늘의 조언 카드 (AI)
**동작**
- 카드를 탭해도 아무 일도 일어나지 않는다.
- 길게 누르면 텍스트를 복사할 수 있다.

**상태**
| 상태 | 표시 |
|---|---|
| 생성 중 | 스켈레톤 3줄 + shimmer. 완료되면 단어 단위로 페이드 인한다. |
| 실패 | 카드 안에 "조언을 만들지 못했어요"와 [다시 시도]. |
| API 키 모드 · 오프라인/키 오류 | 카드 안에 안내와 [키 확인]. [키 확인]은 설정 › AI 연결로 이동한다. |
| 민감 내용 감지 | 도움 리소스 카드로 교체한다 (→ Part B 상태 7). |
| AI 불가 | 카드를 숨긴다. |

**출처 라벨**
- iOS: "✦ Apple Intelligence로 기기에서 생성됨"
- Android: "✦ 기기 내 AI로 생성됨"
- API 키 모드(공통): "✦ Gemini (내 API 키)" / "✦ OpenAI (내 API 키)"

**일기 1~2개일 때:** 일기 1개부터 생성한다. 1–2문장으로 짧게 쓰고, 출처 칩은 있는 일기 수만큼만 보여 준다.

#### 3.4 출처 칩 (참고한 일기)
- **동작:** 탭하면 해당 날짜의 일기 상세로 이동한다.
  - iOS: 줌 전환.
  - Android: shared element 전환.
- **상태:** 1–3개, 날짜 오름차순. 생성 중에는 숨긴다.
- **모양:** iOS는 캡슐(radius 999), Android는 M3 Assist chip(radius 8).

#### 3.5 피드백(좋아요/별로예요) · 다시 생성
- 좋아요/별로예요를 탭하면 채워진 아이콘으로 토글되고 햅틱이 울린다.
  - Android 햅틱: `HapticFeedbackConstants.CONFIRM`.
- "별로예요"를 누른 뒤에는 "다른 조언 보기" 인라인 제안이 나타난다.
- 다시 생성(↻)을 누르면 카드가 생성 중 상태로 바뀐 뒤 새 조언을 보여 준다.
- 생성 중에는 세 버튼 모두 비활성이다.
- 터치 영역: iOS 44pt / Android 48dp.
- 저장 위치: `AIText.feedback` (`helpful` / `notHelpful`).

#### 3.6 오늘의 글감 카드
**동작**
- 쓰기 버튼을 누르면 질문이 상단 프롬프트로 붙은 새 일기 에디터가 열린다.
  - 버튼 라벨: iOS "쓰기", Android "이 질문으로 쓰기". Android는 FAB가 일반 쓰기를 담당하므로 라벨로 역할을 구분한다.
- "다른 질문"을 누르면 질문만 다시 생성한다.

**상태**
- 오늘 일기가 있으면 이 카드 대신 3.7 미리보기 카드를 보여 준다.
- AI 불가면 ✦ 없이 고정 문구를 보여 준다.

#### 3.7 오늘의 일기 미리보기 (오늘 일기 있음)
- **내용:** 제목(세리프), 본문 2줄, 작성 시각, 오른쪽 56pt 썸네일(사진이 있을 때).
- 제목이 없으면 본문 첫 줄을 제목으로 쓴다 (`Journal.displayTitle`).
- **동작:** 카드 전체를 탭하면 오늘 일기 상세로 이동한다(줌 / shared element).

#### 3.8 나의 원칙 버블 (일기 3개 이상)
**배치·모양**
- 최대 5개. 면적은 중요도에 비례하고, 최소 지름은 64다.
- 색은 최근성 5단계 (principle scale, → ../DesignSystem).
- 버블은 영역 중앙으로 모이는 스프링 물리로 움직인다.
- 새 원칙은 아래에서 떠오르고, 사라지는 원칙은 축소되며 페이드 아웃한다.
- 동작 줄이기(Reduce Motion)가 켜져 있으면 정적으로 배치한다.

**탭 → 관련 일기 메뉴** (상세로 바로 이동하지 않는다)
- 헤더: 키워드 + "N개의 일기에서 발견". 클릭할 수 없다.
- 항목: 관련 일기 최대 3개, 영향도(`influence`) 순. 각 항목은 제목 + 날짜이고, 제목이 없으면 본문 첫 줄을 쓴다.
- 항목을 탭하면 메뉴가 닫히고 일기 상세로 이동한다.
- 메뉴가 열려 있는 동안 물리 애니메이션을 멈춘다.

**메뉴 표현의 iOS/Android 차이**
- **iOS:** contextMenu (탭으로 열림).
  - 버블이 1.08배 확대되고 그림자로 떠오른다. light impact 햅틱.
  - 탭 바를 포함해 배경 전체가 블러 처리된다. 바깥을 탭하면 닫힌다.
  - 아래 공간이 부족하면 위로 열린다.
  - 동작 줄이기: 확대 없이 크로스페이드.
- **Android:** 버블에 앵커된 DropdownMenu. 배경 블러·딤이 없다.
  - 버블에 포커스 링을 그린다(2dp 브랜드 색, 4dp 간격). 햅틱 `CONTEXT_CLICK`.
  - 메뉴 컨테이너 radius 16. 항목 높이 56dp(2줄), 누름 state layer 8%.
  - 기본 위치는 버블 아래 시작점 정렬이다. FAB·Navigation Bar와 겹치면 위로 뒤집혀 열린다.
  - 바깥 탭이나 시스템 뒤로를 누르면 메뉴만 닫힌다(화면 뒤로가기 아님).

**섹션 헤더**
- 부제: "일기 N개에서 찾았어요".
- "전체 보기"를 누르면 원칙 탭으로 전환한다.

#### 3.9 원칙 빈 상태 + 진행 표시 (일기 1~2개)
- 문구: "일기가 3개 이상 쌓이면 원칙을 찾아드려요" + 3칸 진행 바("2 / 3"). 범례와 "전체 보기"는 숨긴다.
- 세 번째 일기를 저장하는 즉시, 이 자리에서 버블이 아래에서 떠오르며 등장한다. 동작 줄이기가 켜져 있으면 크로스페이드한다.
- 접근성: progressbar "원칙 분석까지 2 / 3".

#### 3.10 범례
- 표시 내용: "최근 ● … ● 오래됨 · 크기 = 등장 빈도".
- 버블이 있을 때는 항상 보여 준다. 색만으로 의미를 전달하지 않기 위해서다.

#### 3.11 이번 주 요약 (AI, 접힘)
- 접힌 상태: "10월 26일–30일 · 일기 4개 · 차분함이 늘었어요".
- 탭하면 제자리에서 펼쳐진다: 주간 요약 3–4문장 + 감정/주제 흐름 + 출처 칩. 다시 탭하면 접힌다.
- 이번 주 일기가 0개이거나 전체 일기가 3개 미만이면 숨긴다.
- 생성 중·실패 상태는 조언 카드와 같다.

#### 3.12 AI 경고 버튼 (AI 없음 / 모델 다운로드 중)
- **노출 조건:** 기기 내장 AI와 사용자 API 키가 **모두** 불가일 때만 보여 준다. 모델 다운로드 중에도 보여 준다.
- 사용할 수 있게 되면 축소 + 페이드로 사라진다.

**탭하면 열리는 경고**
- 제목: 기본 "AI 기능을 사용할 수 없어요". 모델 다운로드 중일 때만 "AI를 준비하고 있어요".
- 본문: 원인 문장 + 공통 문장 "일기 쓰기는 그대로 사용할 수 있어요."

| 원인 | iOS | Android |
|---|---|---|
| 미지원 기기 | 이 기기는 Apple Intelligence를 지원하지 않아요. | 이 기기는 Gemini Nano를 지원하지 않아요. |
| AI 꺼짐 | 설정에서 Apple Intelligence가 꺼져 있어요. | 기기 내 AI(Gemini Nano)가 꺼져 있어요. |
| 다운로드 중 | AI 모델을 내려받고 있어요. 준비되면 자동으로 켜져요. | (동일) |

**버튼**
- [확인](기본, 강조): 닫히고 홈에 그대로 머문다.
- [API 키 연결]: 닫힌 뒤 설정 › AI 연결로 이동한다.
  - 키를 처음 연결하는 경우 외부 전송 동의 시트(바텀시트)가 먼저 뜬다.

**iOS/Android 차이**
- **iOS**
  - 버튼: 내비게이션 바 (+) 왼쪽 ToolbarItem, SF Symbol `exclamationmark.triangle.fill`.
  - 경고: 시스템 Alert. 아이콘이 없고, iOS 26 캡슐 버튼 2개를 쓰며 확인이 `.defaultAction`이다.
  - 바깥을 탭해도 닫히지 않는다. VoiceOver 포커스는 제목으로 간다.
- **Android**
  - 버튼: Top App Bar actions의 IconButton(48dp 터치, 40dp 앰버 원 #D97A1E), Material Symbols Rounded "warning".
  - 경고: M3 AlertDialog. 아이콘 슬롯(#B35F0F)에 제목이 가운데 정렬된다.
  - 텍스트 버튼은 우측 정렬이고 확인이 맨 오른쪽이다.
  - 스크림을 탭하거나 시스템 뒤로를 누르면 닫힌다(`dismissOnClickOutside = true`).

#### 3.13 일기 앱 모드 전용 요소 (AI 없음)
**오늘의 일기 카드**
- 문구: "오늘 하루를 몇 줄로 남겨보세요 / 짧아도 괜찮아요."
- iOS는 카드 안에 [쓰기] 버튼이 있다.
- Android는 카드에 버튼이 없고 FAB가 담당한다. 보조 문구: "…오른쪽 아래 '쓰기'를 눌러 시작하세요."
- 오늘 일기가 있으면 미리보기로 바뀌고, 탭하면 상세로 간다.

**이번 주 스트립 (월–일 7칸)**
- 날짜를 탭하면, 일기가 있는 날은 상세로, 없는 날은 그 날짜로 새 일기 에디터를 연다.
- 미래 날짜는 흐리게 표시하고 탭할 수 없다.
- 점 = 일기 있음.
- 오늘 표시: iOS는 테두리, Android는 채워진 컨테이너(#DCE0F4).
- 좌우로 스와이프하면 이전 주로 이동한다.
- "캘린더"를 누르면 기록 탭(캘린더 모드)으로 간다.

**최근 기록**
- 최근 5개. 각 항목은 날짜 블록 + 제목 + 본문 2줄 + 썸네일이고, AI 키워드 칩은 없다.
- 항목을 탭하면 상세로 간다.
- "모두 보기"를 누르면 기록 탭으로 간다.

#### 3.14 첫 실행 전용 요소 (일기 0개)
- **일러스트:** 라인 드로잉 1색 + 원칙 색 3점. 다크 모드에서는 선 색을 #A39D96로 바꾼다.
- **안내:** "첫 일기를 써보세요 / 몇 줄이면 충분해요. 일기가 쌓이면 그 안에서 나만의 원칙을 찾아드릴게요."
- **첫 일기 쓰기:**
  - iOS: 화면 안 Primary 버튼 + 내비게이션 바 (+).
  - Android: 화면 안 버튼 없이 Extended FAB "첫 일기 쓰기"가 대신한다.
  - 저장 후 홈은 "일기 1~2개" 상태가 된다.
- **예시 질문 3개(고정, ✦ 없음, AI 가능/불가 공통):**
  - "오늘 가장 오래 머문 생각은 무엇이었나요?"
  - "최근 누군가에게 고마웠던 순간이 있나요?"
  - "내일의 나에게 한마디 한다면?"
  - 탭하면 해당 질문이 프롬프트로 붙은 새 에디터가 열린다. Android 행 높이 56dp.
- **프라이버시 한 줄:**
  - 기기 AI: "모든 분석은 이 기기 안에서 이루어져요"
  - API 키 모드: "요약·키워드만 Gemini(내 키)로 전송돼요"
  - AI 없음: 숨기고 AI 경고 버튼을 노출한다.

#### 3.15 탭 바 / Navigation Bar
- 탭: 오늘 / 기록 / 원칙 / 설정. AI가 없으면 원칙 탭을 숨겨 3탭이 된다.
- 선택 색은 #2E3A6E, 비선택 색은 #4A4540.
- **iOS:** 하단 플로팅 Liquid Glass 탭 바.
- **Android:** Navigation Bar. 활성 탭 인디케이터 필은 56×32다.
  - Medium 이상(펼침·태블릿)에서는 Navigation Rail로 바뀐다.
  - 시스템 뒤로는 Predictive Back.

### 4. 데이터 의존
- `Journal`: `day`, `title`/`displayTitle`, `previewText`, `thumbnail`, `createdAt`(작성 시각), `prompt`(글감에서 시작한 경우).
- `AIText`: 조언·요약·글감에 쓴다. `text`, `engine`(→ `sourceLabel`), `sourceJournalIDs`(출처 칩), `feedback`.
- 원칙 집계: `JournalKeyword.name`·`influence`·`isExcluded`를 일기 전체에서 모아 등장 수, 최근성, 관련 일기 상위 3개를 만든다.

### 5. 접근성
- 버블 라벨 예시:
  - iOS: "원칙: 경청, 최근, 7개 일기에서 등장"
  - Android: 같은 내용 뒤에 ", 두 번 탭하여 관련 일기 보기"를 덧붙인다.
- VoiceOver: 버블을 더블탭하면 메뉴가 열리고 포커스가 메뉴 헤더로 간다. 문지르기 제스처로 닫는다.
- 진행 바: "원칙 분석까지 n / 3".
- Dynamic Type / 글꼴 크기에 맞춰 카드 높이가 늘어난다. 고정 높이를 쓰지 않는다.

## Part B — AI 카드 상태 · 다크 모드

### 1. 이 Part는
홈 화면만이 아니라 **AI가 만든 텍스트를 보여 주는 모든 카드**의 상태 규칙과 **다크 모드** 규칙을 정한다.
iOS와 Android의 동작은 같고, 라벨 문구만 다르다.

**적용 대상**
- 홈: 오늘의 조언, 이번 주 요약, 오늘의 글감
- 일기 상세: AI 한마디
- 원칙 상세: 정의

> AI 불가(기기 AI와 API 키가 모두 없음)일 때는 카드 자체를 **렌더링하지 않는다**. 빈 자리도 남기지 않는다.
> 아래 상태들은 AI를 쓸 수 있을 때만 해당한다.

### 2. AI 카드 상태 머신
```
idle ─▶ generating ─▶ streaming ─▶ done ─(피드백)─▶ done(feedback)
             │                       │
             ├─▶ failed (n<3) ─ 다시 시도 ─▶ generating
             ├─▶ failed (n≥3) ─▶ resting ("오늘은 쉬어 갈게요")
             ├─▶ offline (API 키 모드만) ─ 연결 복구 시 자동 재시도
             ├─▶ keyError (API 키 모드만)
             └─▶ sensitive (도움 리소스 카드로 교체)
```

| # | 상태 | 표시 | 규칙 |
|---|---|---|---|
| 1 | 생성 중 | 헤더 "✦ 오늘의 조언" + 스켈레톤 3줄. 왼쪽에서 오른쪽으로 shimmer(1.4초 반복). 하단 "기기에서 만드는 중…" | 피드백, 다시 생성, 출처 칩을 숨긴다. 동작 줄이기가 켜져 있으면 shimmer 대신 정적 회색. |
| 2 | 스트리밍 | 단어 단위로 페이드 인(단어당 120ms) | 카드 높이를 완료 높이로 미리 잡지 않고 자연스럽게 늘린다. 완료 후 출처 칩과 피드백을 페이드 인. 스크린리더는 완료 후 한 번에 읽는다. |
| 3 | 완료 + 피드백 | 본문 + 엔진 라벨 + 피드백(도움됨 / 도움 안 됨) + ↻ | 하나를 고르면 채운 아이콘으로 바뀌고 다른 하나는 숨긴다. 다시 탭하면 해제한다. "도움 안 됨"을 고르면 카드 아래에 "다른 조언 보기" 텍스트 버튼 한 줄. |
| 4 | 생성 실패 | "조언을 만들지 못했어요. 잠시 후 다시 시도해 주세요." + [다시 시도] | AI 틴트 대신 **중립 배경**을 쓴다. 실패가 AI 결과물처럼 보이지 않게 하기 위해서다. 3회 연속 실패하면 [다시 시도] 대신 "오늘은 쉬어 갈게요"로 카드를 축소한다. |
| 5 | 오프라인 (API 키 모드만) | "인터넷에 연결되면 조언을 만들어 드릴게요." + "Gemini (내 API 키)는 인터넷이 필요해요. 일기 쓰기는 그대로 돼요." | 기기 내장 AI 모드에서는 이 상태가 나타나지 않는다. 연결이 돌아오면 자동으로 다시 시도한다. |
| 6 | API 키 오류 | 제목 "내 API 키를 확인해 주세요" + "Gemini가 키를 받지 않았어요. 사용 한도를 넘었거나 키가 만료됐을 수 있어요." + [키 확인] | [키 확인]은 설정 › AI 연결(연결됨 화면, 상태 카드가 오류로 표시)로 간다. 원인 문구: 만료·무효 "키가 올바르지 않아요", 한도 초과 "사용 한도를 넘었어요". |
| 7 | 민감한 내용 감지 | "마음이 많이 무거운 날이었나 봐요 / 혼자 견디지 않아도 괜찮아요. 지금 이야기를 들어줄 곳이 있어요." + [109 자살예방상담전화] + [다른 상담 창구] | 조언 대신 보여 준다. ✦, 피드백, 다시 생성이 없고 접히지 않는다. 차분한 흰 카드이고 경고색을 쓰지 않는다. 다른 창구는 1577-0199 정신건강위기상담 등. 감지는 **기기 안에서만** 한다. Android 전화 버튼은 `ACTION_DIAL`. |

**카드별 차이**
- **오늘의 조언:** 스켈레톤 3줄. 출처 칩(참고한 일기 1–3개)이 있다.
- **이번 주 요약:** 출처 칩이 있다. 기본은 접혀 있다.
- **AI 한마디:** 스켈레톤 2줄. 출처 칩이 없다(출처가 그 일기 자체). 처음 펼칠 때 생성한다.
- **원칙 정의:** 1문장. 출처 칩이 없다.

### 3. 엔진별 출처 라벨
- 위치: 카드 하단 왼쪽에 고정한다.
- 스타일: Caption 11.5–12, text/secondary.
- 출처 칩(참고한 일기)과는 별개다. 출처 칩은 홈 조언과 주간 요약에만 있다.

| 엔진 (`AIEngine`) | 라벨 |
|---|---|
| `appleIntelligence` (iOS 기기 내장) | ✦ Apple Intelligence로 기기에서 생성됨 |
| `geminiNano` (Android 기기 내장) | ✦ 기기 내 AI로 생성됨 (Gemini Nano 표기 가이드 확인 후 확정) |
| `geminiAPIKey` | ✦ Gemini (내 API 키) |
| `openAIAPIKey` | ✦ OpenAI (내 API 키) |
| (향후, 이번 범위 밖) 블루투스 릴레이 | ✦ ○○의 iPhone에서 생성됨 |

### 4. 다크 모드 규칙
- **전환:** 시스템 설정을 따른다. 앱 안에 별도 토글은 없다. 전환할 때 크로스페이드한다.
- **원칙:** 레이아웃과 동작은 Light와 같고, **토큰만 바꿔 끼운다**. 기준값은 ../DesignSystem 토큰 시트의 Dark 열이다.

| bg/canvas | #141312 | 순검정 대신 따뜻한 거의-검정 |
| bg/surface | #1E1C1B + 1px #2E2B28 외곽선 | 그림자 대신 외곽선을 쓴다 |
| text primary / secondary | #F2EFEA / #A39D96 | 캔버스 대비 7.0:1 |
| brand/primary | #AEB8F0 버튼 + 글자 #1A2150 | Light의 잉크 인디고를 밝기 보정 |
| ai/tint · ai/accent | #221F2E 카드 · #B3A8F0 (✦, 라벨) | |
| principle 5단계 | #C77562 #C99472 #BBA676 #9BAE80 #82A38A | 채도와 명도를 낮춘다. 글자는 #141312(대비 ≥ 5:1) |
| 사진 · 일러스트 | 사진은 그대로 | 라인 일러스트는 선 색을 #A39D96로 바꾼다. 버블 그림자는 없다. |

### 5. 구현 메모
- 상태는 `AIText?`와 별도의 로딩/에러 enum으로 표현한다. 성공 결과(`AIText`)는 캐시하고, 실패 상태는 저장하지 않는다.
- 연속 실패 횟수는 카드별로 하루 단위로 센다.
- 민감 내용 감지 결과는 서버(API 키 모드 포함)로 보내지 않는다.
