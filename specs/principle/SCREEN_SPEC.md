# 원칙

## 1. 이 화면은
AI가 일기에서 추출한 키워드를 모아 **지금의 원칙 상위 5개**와 **지나간 원칙** 기록을 보여 주는 탭이다.
홈의 원칙 버블을 리스트로 보여 주는 화면이기도 해서, 스크린리더 사용자가 버블 대신 쓰는 경로가 된다.

## 2. 원칙 계산 규칙
| 규칙 | 내용 |
|---|---|
| 재계산 시점 | 일기를 저장한 뒤 **하루 1번(밤)**. 쓰는 도중 순위가 흔들리지 않게 하기 위해서다. 영구 삭제나 키워드 제외는 다음 계산에 반영한다. 더보기 › "원칙 다시 분석하기"로 수동 실행할 수 있다. |
| 순위 | 등장 빈도(관련 일기 수) 순으로 최대 5개. |
| 최근성 | 마지막 등장일을 기준으로 5단계로 나누고, 원 색(principle scale)으로 표시한다. 홈 버블과 같은 기준이다. |
| 고정 | 최대 2개. 고정한 원칙은 순위 밖으로 밀려도 목록과 홈 버블에 남는다. 2개를 넘기려 하면 안내를 보여 준다. |
| 숨김 | 숨긴 원칙은 홈과 목록에서 빠지고 다음 순위가 올라온다. 더보기 › "숨긴 원칙 보기(N)"에서 다시 보이게 할 수 있다. |
| "새로" 배지 | 이번 갱신에서 처음 상위 5개에 들어온 원칙에 붙인다. |
| 지나간 원칙 | 5위 밖으로 나간 원칙을 최신순으로 보여 준다. 예: "9월 · 3주 동안 1위". |
| 최소 데이터 | 일기 3개 미만이면 빈 상태를 보여 준다(진행 표시 n/3). |

## 3. 원칙 목록

### 3.1 상단
- Large Title "원칙".
- 부제: "일기 12개에서 찾았어요 · 10월 30일 갱신" (분석에 쓴 일기 수 + 마지막 갱신일).
- **더보기:** 숨긴 원칙 보기(N) / 원칙 다시 분석하기.
  - iOS ⋯, Android ⋮.

### 3.2 지금의 원칙 (순위 리스트)
**행 구성**
- 순위.
- 최근성 색 원 + 이름. 고정했으면 핀, 새로 들어왔으면 "새로" 배지.
- 보조 텍스트: "7편 · 마지막 10월 27일". 고정된 원칙은 "5편 · 고정됨".
- 빈도 막대: 1위 대비 비율. **iOS에만 있다.** Android는 행 폭을 ⋮ 버튼에 쓰기 때문에 막대를 생략하고 "N편"으로만 표기한다.

**탭:** 원칙 상세로 간다.

**고정 / 숨기기**
- **iOS:** 왼쪽으로 스와이프하면 고정 / 숨김 액션이 나온다 (`List` + `swipeActions`). 길게 누르면 같은 메뉴가 열린다.
- **Android:** 행 끝에 보이는 ⋮ IconButton을 누르면 DropdownMenu(고정 / 숨기기)가 열린다.
- 숨기면 실행 취소 토스트/Snackbar를 띄운다.

### 3.3 지나간 원칙 (타임라인)
- 항목: 시기 + 기간·순위 + 이름. 예: "9월 · 3주 동안 1위 / 인내".
- 탭하면 과거 원칙 상세로 간다. 이 상세에는 고정 버튼 대신 "다시 원칙으로 고정"이 있다.
- 지나간 원칙이 없으면 섹션을 숨긴다.

### 3.4 그 외
- Android는 원칙 탭에서도 아이콘 FAB(새 일기)를 유지한다. iOS는 (+)가 없다.
- 빈 상태(일기 3개 미만): 홈과 같은 진행 표시(n / 3)와 문구를 보여 준다.
- AI 불가: 원칙 탭 자체를 숨긴다(3탭 구성).

## 4. 원칙 상세

### 4.1 상단 바
- **고정(핀):** 고정을 켜고 끈다. 채워진 핀이 고정 상태다. 최대 2개.
- **더보기:** 숨기기 / 이름 바꾸기 / 다시 분석.
- **숨기기:** 확인 없이 목록으로 돌아가고 "경청을 숨겼어요 · 실행 취소"를 띄운다.
- **iOS:** 핀과 ⋯를 한 Glass 캡슐로 묶는다.
- **Android:** 앱 바 actions에 IconButton 2개(핀, ⋮). 실행 취소는 Snackbar.

### 4.2 원칙 헤더
- 최근성 색 원 + 이름(세리프).
- 순위와 최근성을 텍스트로 함께 쓴다. 예: "지금의 원칙 1위 · 최근". 색만으로 의미를 전달하지 않기 위해서다.
- 과거 원칙이면: "9월의 원칙 · 지금은 순위 밖".

### 4.3 정의 (AI 1문장)
- 헤더: "✦ 이 원칙은".
- 관련 일기를 바탕으로 "~하려는 태도예요" 형식의 1문장을 만든다.
  - 예: "다른 사람의 말을 끝까지 듣고, 내 생각보다 질문을 먼저 꺼내려는 태도예요."
- 생성 중에는 스켈레톤, 실패하면 카드 안에 [다시 시도]를 보여 준다.
- 관련 일기가 늘면 다음 갱신 때 다시 쓴다.
- 엔진 라벨은 다른 AI 카드와 같다.

### 4.4 요약 수치 (3칸)
- 처음 등장(9월 14일) / 관련 일기(7편) / 마지막(10월 27일).
- 탭해도 아무 동작이 없다.

### 4.5 빈도 추이 미니 차트
- 최근 8주의 주간 등장 횟수를 막대로 보여 준다.
  - 축 라벨: 9/7 … 10/19, 이번 주.
  - 이번 주만 브랜드 색(#2E3A6E)이고, 0회인 주는 2pt 바닥선으로 그린다.
- 막대를 탭하면 그 주의 관련 일기만 아래 목록에 남긴다. 다시 탭하면 필터를 해제한다.
- 스크린리더용 요약 라벨을 제공한다. 예: "최근 8주 동안 7번, 이번 주 2번".

### 4.6 관련 일기
- 최신 3편을 미리 보여 준다(날짜 + 제목). 행을 탭하면 일기 상세로 간다.
- "7편 모두 보기"를 누르면 관련 일기 전체 화면으로 간다. 키워드 시트와 같은 내용이다.
  - iOS: 섹션 헤더 오른쪽 텍스트 링크.
  - Android: 목록 아래 Outlined 버튼.

## 5. 데이터 의존
- 원칙 집계: 모든 `Journal.keywords` 중 `isExcluded == false`인 것을 `name`별로 묶는다.
  - 집계값: 관련 일기 수, 처음/마지막 등장일, 주간 횟수, `influence` 합.
- 원칙별로 저장하는 값: 고정 여부, 숨김 여부, 사용자 지정 이름, 순위 이력(지나간 원칙용), AI 정의 텍스트(`AIText`).
- AI 정의는 `AIText`의 `sourceJournalIDs`로 관련 일기를 참조한다.
